# AZ-104 Lab 03 – Manage Azure Resources using ARM Templates and Bicep

## Objective
Understand how Infrastructure as Code (IaC) is implemented in Azure using Azure Resource Manager (ARM)
templates and Azure Bicep to automate and standardize resource deployments.

## Lab Scenario
The organization wants to reduce manual deployments, minimize human error, and increase consistency
by automating Azure resource provisioning using templates.

## Concepts Covered
- Infrastructure as Code (IaC)
- Azure Resource Manager (ARM)
- ARM template structure
- Parameters and variables
- Azure Cloud Shell (PowerShell & CLI)
- Azure Bicep
- ARM vs Bicep comparison

## What I Practiced
- Created Azure resources manually and exported ARM templates
- Edited ARM templates to redeploy resources
- Deployed templates using Azure PowerShell
- Deployed templates using Azure CLI
- Deployed resources using Azure Bicep

## Key Learnings
- ARM is the core deployment engine in Azure
- ARM templates define infrastructure declaratively
- Parameters enable template reuse
- Bicep simplifies ARM authoring but uses ARM internally
- IaC is essential for DevOps and automation

## Interview Notes
- ARM templates are JSON-based declarative files
- Bicep is a higher-level language that compiles to ARM
- ARM templates can be deployed via Portal, PowerShell, CLI, or pipelines
- IaC ensures consistency, repeatability, and scalability
