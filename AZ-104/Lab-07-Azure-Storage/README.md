# AZ-104 Lab 07 – Manage Azure Storage

## Objective
Implement secure, cost-effective Azure Storage using blobs and file shares.

## Services Used
- Azure Storage Account
- Blob Containers
- Azure File Shares
- Service Endpoints
- Lifecycle Management
- SAS

## Key Learnings
- Storage security is enforced at account level
- Network rules override authentication
- Lifecycle rules optimize cost
- SAS enables temporary access
- Azure Files can replace on-prem file servers
