# AZ-104 Lab 06 – Network Traffic Management

## Objective
Understand how Azure manages incoming traffic using Azure Load Balancer and Azure Application Gateway.

## Concepts Covered
- Layer 4 vs Layer 7 load balancing
- Azure Load Balancer architecture
- Azure Application Gateway architecture
- Health probes
- Path-based routing
- Web traffic management

## Key Learnings
- Azure Load Balancer distributes traffic based on IP and port
- Application Gateway enables intelligent HTTP routing
- Path-based routing is only possible at Layer 7
- Choosing the right load balancer depends on application needs
