# AZ-104 Lab 08 – Manage Virtual Machines

## Objective
Understand Azure virtual machines, scaling methods, availability zones, and VM Scale Sets.

## Key Topics Covered
- Azure Virtual Machines
- Availability Zones
- Vertical & Horizontal Scaling
- VM Disk Management
- Virtual Machine Scale Sets (VMSS)
- Autoscaling
- Azure PowerShell & CLI
- VM Deallocation and Cost Control

## What I Practiced
- Deployed zone-resilient VMs
- Resized VM compute and storage
- Created VM Scale Sets
- Configured autoscaling rules
- Created VMs using PowerShell and CLI
- Optimized cost using deallocation

## Key Learnings
- VMSS simplifies scaling and management
- Autoscaling improves availability and cost efficiency
- Deallocation stops compute billing
- PowerShell and CLI enable automation

## Interview Notes
Azure VMs support both vertical and horizontal scaling. VM Scale Sets automate horizontal scaling and integrate with load balancers. Availability Zones provide high availability, and deallocation helps reduce costs.
