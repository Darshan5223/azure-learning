# AZ-104 Lab 01 – Manage Microsoft Entra ID Identities

## Objective
Understand identity management in Azure using Microsoft Entra ID, including users, guest users, and groups.

## Concepts Covered
- Tenant and subscription relationship
- Internal (Member) users
- External (Guest) users
- Security groups
- Assigned vs Dynamic group membership

## What I Practiced
- Created internal users
- Invited a guest user
- Created a security group
- Added users to group (Assigned membership)

## Key Learnings
- Tenant is the identity boundary for Azure
- Access should always be assigned to groups
- Guest users authenticate externally but are authorized internally

## Interview Notes
Assigned membership is manual, while dynamic membership is rule-based and automatic.
