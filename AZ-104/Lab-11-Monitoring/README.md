# AZ-104 Lab 11 – Implement Monitoring

## Objective
Implement Azure Monitor to track infrastructure health, create alerts, configure notifications, and analyze logs.

## Services Used
- Azure Monitor
- Log Analytics
- Alerts
- Action Groups
- Virtual Machines

## Tasks Completed
- Deployed VM using ARM template
- Enabled VM Insights
- Created Activity Log alert
- Configured email notification using Action Group
- Triggered alert by deleting VM
- Configured alert processing rule
- Queried logs using KQL

## Key Learnings
- Azure Monitor centralizes observability
- Alerts automate issue detection
- Action Groups notify admins
- Log Analytics provides deep insights
- KQL enables advanced monitoring queries

## Interview Notes
Azure Monitor supports metrics, logs, alerts, and diagnostics for Azure resources. Activity Log alerts track management operations, while metric alerts track performance.
