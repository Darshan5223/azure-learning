# AZ-104 Lab 10 – Implement Data Protection

## Objective
Understand Azure Backup and Azure Site Recovery to protect virtual machines from data loss and regional outages.

## Services Used
- Azure Virtual Machines
- Recovery Services Vault
- Azure Backup
- Azure Site Recovery
- ARM Templates

## Key Learnings
- VM backups require Recovery Services Vault
- Backup policies control retention and frequency
- Soft Delete prevents immediate deletion
- Azure Site Recovery enables cross-region failover
- Backup ≠ Disaster Recovery

## Real-World Observations
- Recovery Services Vault deletion is blocked during retention
- Restore points are managed by Azure
- Deletion delays are intentional for security
