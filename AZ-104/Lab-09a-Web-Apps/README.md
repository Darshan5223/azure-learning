# AZ-104 Lab 09a – Implement Web Apps

## Objective
Deploy and manage Azure Web Apps using App Service, GitHub integration, deployment slots, and scaling concepts.

## Tasks Completed
- Created Azure Web App (PHP, Linux)
- Created staging deployment slot
- Configured GitHub deployment
- Swapped staging to production
- Explored scaling limitations

## Key Learnings
- Azure App Service is a PaaS offering
- Deployment slots enable zero-downtime releases
- Scaling features depend on App Service Plan
- GitHub integration enables CI/CD

## Interview Notes
Deployment slots allow blue-green deployment. Autoscaling requires Premium App Service plans.
