# AZ-104 Lab 05 – Implement Intersite Connectivity

## Objective
Understand how Azure virtual networks communicate, how connectivity is enabled using virtual network peering, and how traffic flow is controlled using custom routes.

## Tasks Completed
- Created virtual machines in separate virtual networks
- Verified default network isolation
- Tested connectivity using Network Watcher
- Configured virtual network peering
- Verified connectivity using Azure PowerShell
- Implemented user-defined routes to control traffic flow

## Key Concepts Learned
- Virtual network isolation
- Virtual network peering
- Microsoft backbone traffic
- Network Watcher diagnostics
- PowerShell connectivity testing
- User-defined routes and future NVAs
